# 🚀 GUIDE RAPIDE - Mise en ligne Saint-Eloi

## Étape 1 : Créer un compte GitHub
1. Aller sur **github.com**
2. Cliquer "Sign up"
3. Créer un compte (gratuit)

## Étape 2 : Créer le repository
1. Cliquer le **+** en haut à droite → "New repository"
2. Nom : `saint-eloi`
3. Cocher **Public**
4. Cliquer **Create repository**

## Étape 3 : Uploader les fichiers
1. Sur la page du nouveau repo, cliquer **"uploading an existing file"**
2. Glisser-déposer TOUS ces fichiers :
   - `index.html`
   - `config.json`
   - `manifest.json`
   - `sw.js`
   - `icon.svg` (ou les PNG si tu les as créés)
3. Cliquer **Commit changes**

## Étape 4 : Activer GitHub Pages
1. Aller dans **Settings** (onglet en haut)
2. Dans le menu à gauche, cliquer **Pages**
3. **Source** : Deploy from a branch
4. **Branch** : `main` et `/ (root)`
5. Cliquer **Save**
6. Attendre 2-3 minutes...

## ✅ C'est en ligne !
Ton site sera à : `https://TON-PSEUDO.github.io/saint-eloi/`

---

## 📝 Pour modifier ensuite

1. Aller sur ton repo GitHub
2. Cliquer sur **config.json**
3. Cliquer le crayon ✏️
4. Modifier ce que tu veux
5. Cliquer **Commit changes**
→ Mis à jour en 30 secondes !

---

## 🖼️ Créer les icônes (optionnel mais recommandé)

Pour que l'app s'affiche bien sur téléphone :

1. Aller sur **canva.com** ou **figma.com**
2. Créer une image carrée 512x512
3. Fond vert (#2c5530)
4. Ajouter 🏠 au centre
5. Exporter en PNG
6. Sauvegarder comme `icon-512.png`
7. Redimensionner en 192x192 → `icon-192.png`
8. Uploader sur GitHub

---

**C'est tout ! Bonne mise en ligne 🎉**
