Règlement Intérieur

Afin de garantir le confort et la tranquillité de tous, merci de respecter ces règles.

ℹ️ Note : Toutes les règles peuvent être adaptées si besoin. Demandez à la direction.

🛡️ 1. SÉCURITÉ ET ACCÈS

  • Accès réservé : L'accès est strictement réservé aux résidents. Les visites extérieures sont interdites sauf autorisation.
  • Sécurité du portail : Le code est strictement personnel. Le portail doit rester fermé après chaque passage.

🧹 2. HYGIÈNE ET ENTRETIEN

  • Propreté : Les chambres doivent être maintenues propres. Les poubelles doivent être vidées chaque semaine.
  • Aération et Tabac : Il est interdit de fumer dans les chambres. Aérez quotidiennement.
  • Nourriture : Il est interdit de cuisiner dans les chambres. Pas de stockage de denrées périssables.
  • Chauffage : Radiateurs max 21°C. Interdit de sécher du linge sur les radiateurs.

🍽️ 3. ESPACES COMMUNS & CUISINE

  • Respect des lieux : Les parties communes doivent être nettoyées après utilisation.
  • Cuisine partagée : Accès 08h00-22h00. Créneaux cuisine : 11h-14h et 18h-21h.
  • La vaisselle doit être faite et rangée après chaque repas.

🧺 4. LINGE ET BUANDERIE

  • Draps : Changement le week-end. Draps sales dans le sac prévu.
  • Machines : 1 fois/semaine par personne. Vêtements personnels uniquement.

🤝 5. VIE EN COMMUNAUTÉ

  • Savoir-vivre : Tenue correcte et politesse appréciées.
  • Tranquillité : Silence à partir de 23h00.
  • Respect d'autrui : Vol interdit. Respectez le personnel.
  • Appareils électriques : Soumis à autorisation préalable.
Participation : Pour ceux qui le souhaitent, il est possible de participer à la vie du lieu sur simple demande.

🚪 6. DÉPART

  • Le jour du départ, la chambre doit être libérée à 11h00 maximum.
LE NON-RESPECT DE CES RÈGLES ENTRAÎNERA UNE EXPULSION DÉFINITIVE, SANS PRÉAVIS NI REMBOURSEMENT.
